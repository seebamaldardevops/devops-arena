DevOps Pipeline

Every change to DEVOPS ARENA travels through this automated pipeline.

  1. DeveloperWrites and edits the code
  2. GitTracks every change locally
  3. GitHubStores the code online and notifies Jenkins
  4. JenkinsAutomation server that runs the pipeline
  5. Automated TestingChecks files, elements and health
  6. Docker BuildPacks the website into an image
  7. Docker ContainerRuns the image
  8. NginxServes the website inside the container
  9. AWS EC2Cloud server that hosts the container
  10. Live DEVOPS ARENAPlayable on the internet
